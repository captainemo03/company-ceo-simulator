# Liberty Bay city asset contract

The runtime looks for licensed, imported prefabs at these Resources paths:

- `City/Companies/player/Headquarters`
- `City/Companies/northstar/Headquarters`
- `City/Companies/meridian/Headquarters` and `Factory`
- `City/Companies/atlas/Headquarters` and `ContainerTerminal`
- Licensed vehicle prefabs can be placed in `City/Vehicles` and assigned to `CEOCommuteController` or spawned by a traffic manager.

The repository currently contains the CC0 office/character assets only. Do not replace the labelled scaffolds with unlicensed or placeholder human/vehicle models. Add a real asset and its license file here before enabling it in a release build.
