# Product asset contract

`ProductDesignStudio` currently renders the smartphone through editable runtime components so every choice is visible in 3D during the first playable scenario.

For a release-quality art pass, add a licensed modular smartphone GLB/FBX pack here and bind its front shell, back shell, display, camera module, buttons and logo anchors to `SmartphonePreview3D`. Keep the supplier license beside the asset. The runtime prototype deliberately does not claim its generated geometry is a licensed final product model.
