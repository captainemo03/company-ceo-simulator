# 3D character assets

The six GLB files in this directory are pinned v1 LOD1 downloads from [tevy.dev](https://tevy.dev), released under **CC0 1.0**:

- Casual Walker — `https://tevy.dev/models/casual-walker/v1/lod1.glb`
- Cyclist — `https://tevy.dev/models/cyclist/v1/lod1.glb`
- Dog Walker — `https://tevy.dev/models/dog-walker/v1/lod1.glb`
- Hiker — `https://tevy.dev/models/hiker/v1/lod1.glb`
- Road Worker — `https://tevy.dev/models/road-worker/v1/lod1.glb`
- Race Marshal — `https://tevy.dev/models/race-marshal/v1/lod1.glb`

The source catalogue and CC0 terms are documented at `https://tevy.dev/docs` and `https://tevy.dev/models.json`. The project keeps these files locally so GitHub Pages does not depend on a third-party model CDN.
